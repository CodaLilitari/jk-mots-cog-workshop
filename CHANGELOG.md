# Changes

## 0.1.1 — 1 October 2026

Workload and storage safeguards.

- Reject private import and managed update output inside Git checkouts, including worktrees and linked paths, without launching Git.
- Bound import discovery, member counts, source objects and provenance occurrences; stop and report incomplete batches when a global limit is reached.
- Stream nested archive members through a temporary spool to limit retained RAM.
- Bound managed integrity scans and archive directory expansion, and keep bulk research outside source repositories in the machine and human instructions.
- Add 20 small synthetic regression tests for these workload boundaries.

## 0.1.0 — 1 October 2026

Initial public research release of the JK / MotS COG Workshop.

- Human COG-writing guide and explicit JKDF2/MotS compatibility guidance.
- Portable machine workflow with measured original-game registration tables.
- Source-backed research notes, attributed public-source catalog and exact
  source identities, separated from privately retained source payloads.
- Original teaching examples with recorded lexical/parser validation limits.
- Portfolio-hosted update feed, verified package installation and update tools.
- Local source import and optional use of a larger user-owned research corpus.
- Optional discovery/correction reporter with an offline, reviewable email draft
  to lilitarikiralv@gmail.com; no automatic sending or telemetry.

The broader acquisition program remains unfinished. Named historical gaps,
incomplete Discord coverage and unperformed retail/network tests remain
research limitations; version 0.1.0 is a usable initial release, not a claim
that every source on the web has been recovered or understood.
